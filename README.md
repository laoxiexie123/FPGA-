# FPGA-

## 基于FPGA的实时姿态控制系统——旋转倒立摆

哈哈队 · V3.2

基于国产高云FPGA实现传感采集、起摆控制、级联双PD平衡、平滑位置轨迹、电机驱动及本地交互。

### 工程入口

使用Gowin打开 [`v3/v3.gprj`](v3/v3.gprj)。目标器件为GW2A-LV55PG484C8/I7，单一50MHz输入时钟。源文件与约束位于 [`v3/src`](v3/src)。

### 主要功能

- 自主起摆、状态捕获与平滑接管，位置外环和角度内环构成级联双PD。
- POSITION STEP：按压进入，顺时针/逆时针分别请求+130/-130计数，名义±45°，每次4秒；再次按压退出。
- CW360 4S：顺时针+1040计数，4秒一圈；保留累计位置目标，不复位计数。
- 五次平滑轨迹，忙时请求忽略且不排队；模式退出不中断已开始的轨迹。
- LCD与EC11旋钮：启停、直立零点校准、状态监测及故障提示。圆形位置图已移除。
- 位置边界、故障锁停及运算溢出保护。
