# V3.2方向单步与顺时针一圈

## 用户已确认规格

基于V3.1独立建立V3.2/v3，顶层top、器件GW2A-LV55PG484C8/I7 revision C，Gowin V1.9.12.03现有工程。唯一50MHz输入M19，20ns约束，所有tick为使能。EC11 AB16/AA16/button AB19与LCD V13/V12/Y13、ADC、电机、编码器引脚沿用V3.1，不改Bank电压或配置方式；外部触点保留两级同步/判稳。仅内部UI事件改变，不新增时钟/CDC/IP。本次无烧录/固化动作，验证目标II级数字仿真。

起摆完成且位置原点锁定后运行菜单两项：

- POSITION STEP：按压进入单步模式；顺时针一格请求+130、逆时针一格请求-130。按压退出，之后可再次进入。
- CW360 4S：按压请求顺时针+1040计数，4秒五次曲线。回到原机械朝向，累计编码器目标保留增加的1040，不复位计数、不反转绕回。

每个请求均用原V3 position_reference：25ms更新、160步、4秒，位置目标交给同一位置PD；不直接发PWM。沿用13PPR×4×20=1040counts/圈，130counts名义45度。计数增加已按用户先前确认对应顺时针。

模式退出即不接收新旋转，不中断正在执行的轨迹。忙时旋转、整圈按压和选择变化均忽略不排队；模式按压退出仍有效，握手忙时也可退出。运行故障或复位清模式和轨迹偏移，不自动重复整圈。起终点越过原±10000位置保护则整次请求拒绝，保护数值不扩大。

整圈4秒是用户明确选择；五次曲线峰值目标速度1.875*1040/4=487.5counts/s，约为45度4秒的8倍。沿用控制器不等于已经实测此速度下立摆稳定；不在本次修改中调PD增益、限幅、起摆参数或滤波。

UI控制器->命令桥->有符号step_counts。桥只允许130/-130/1040三种相对请求值；accept之后锁存位移，帧中改变输入不影响在途轨迹。LCD页面/字体沿用旧实现，运行页增加两项及模式文字和焦点高亮。模式标志与实际moving分开显示。

## 圆点标定历史记录

当前显示仍是相对本次立摆原点的目标/实际偏移，零偏移在圆上方，不代表绝对物理方向。本次不得在没有实机编码器读数和可复现基准时伪造标定。

旧for_rip_top复位计数10000，新版复位0且启动过程再清零。因此即使取得旧固件正下方读数，也必须记录其复位时机械姿态，并建立新版清零时的显示基准关系；单次增量编码器数值不能跨任意复位保存绝对朝向。

串口读取仅COM11、9600 8N1，DTR/RTS=false，不发送控制字节。45秒、60秒两轮均0字节（用户随后说明未按SW4）；再次明确提示后打开120秒窗口，结果仍为0字节、0有效帧。COM11已能正常打开，但没有可用标定值，不能据此推断故障原因。用户随后表示将重新烧录，串口已关闭等待；未自动继续监听或替用户下载。未取得值时不改LCD显示相位或PD原点。
