# SW3平滑位置目标

用户确认13PPR，减速比20，顺时针编码器计数增加。按电机轴13脉冲/圈、AB四倍频计算输出轴1040 counts/圈，每次+130 counts，名义45度。齿轮实际比、间隙和负载会影响机械实际角度，未做实机角度标定。

## 实现

- position_reference.v生成相对本次立摆原点的目标偏移，不直接驱动电机。
- top.v复用20ms key_filter读取SW3；正常立摆、位置原点锁定且motor_permitted时才接受事件。
- ready失效即取消移动、清偏移；不保留旧会话目标。早按不排队，忙时包括完成发布沿的按键也忽略。
- 每1ms使能计时，每25ms推进一次，160步完成。权重为round(65536*(10s^3-15s^4+6s^5))，表内自包含，无外部初始化文件。
- 乘积先寄存，下一50MHz沿发布；目标曲线完成时间是4000个1ms使能加1拍发布延迟，按键接受至首个tick间还有不到1ms相位差。
- 位移以整数计数发布，Q16权重量化；130计数不代表每25ms都移动1计数。4秒是目标曲线时间，不代表机械已到位。
- 每次以当前已完成的目标累加+130，不以实际位置重算，因此不累计跟踪误差。
- 起终点均用扩展位宽检查原点加偏移是否在±position_limit内，超界请求整次拒绝。新请求不改变现有保护阈值。
- balance_control增加position_reference_offset和position_origin_counts控制接口。原点仍由原0.5秒稳定逻辑建立；位置误差=滤波位置-锁定原点-参考偏移。
- 目标偏移在每次5ms控制事务接受时锁存reference_snapshot，不因事务中输入改变混用目标。不清位置滤波、PD差分历史或位置偏置。

## 接口和约束

SW3使用参考Interface_test_new/src/fo_rip_top.cst的key_sw[2]对应U20，LVCMOS15、Bank1.5V。已有本器件pin报告列U20为IOR55[B]，复用名DOUT/WE_N。是否需要额外配置仍以实际布局布线检查为准；不能把综合当引脚检查。SW4既有SSPI专用脚冲突未在本次修改中处理，下载方式尚未确认。

所有逻辑仍为clk_50m单域，SW3经key_filter两级同步，新增SDC异步输入例外。不生成新时钟，不改驱动极性、起摆算法、PD增益或用户已调参数。

## 验证范围

严格整机Verilator lint通过。tb_position_reference.v分别验证正负位移、160点五次曲线、4000tick完成、忙按忽略、重复累加、signed32溢出、绝对位置边界、ready中止和异步复位。巨大signed32位移下Q16权重有量化误差，不声称任意大幅度轨迹都在1count内。

新增接口会改变源码哈希，旧综合和旧复杂度报告不适用于当前版。此次不执行烧写；机械跟踪、移动时立摆稳定性和完整时序收敛需要后续验证。
