# motro电机驱动重构

## 范围

[motro.v](../src/motro.v)接收同域enable和signed16 duty，输出in1_q/in2_q/pwm_q。内部只有50MHz主时钟，不包含低通、斜率限制、PID、起摆状态和运行许可仲裁。旧驱动本身没有低通滤波；原监督器中的阶段变化率限制留待控制层重建。

实现采用固定已确定参数：周期5000拍（10kHz），换向消隐5000拍（100us），命令幅值限255，宽度floor((level*5000+135)/270)。最高宽度4722拍，约94.44%。256个重复分支合并为一个常量算术函数，对level含X/Z仍返回0；不宣称全系统任意X输入等价。

## 保持的逐拍行为

- 复位异步关闭PWM和方向；消隐初始化为5000。
- 停止条件是enable=0或duty=0，下一50MHz沿关PWM并把方向置0/0；不是输入变化即异步关断。
- 停止期间每沿重装消隐并更新有效符号，载波继续自由计数。
- 换向检出当沿关PWM、清脉宽并重装消隐，方向脚暂时保持旧值；不能改成检出当沿直接翻方向。
- 非停止且符号一致时，消隐倒数到0；恢复脉宽仍要等载波零点。
- 方向脚在消隐结束后即可更新，不要求与脉宽装载同沿。
- 同方向中途改变幅值，脉宽到下个载波零点才更新。
- 原实现固定周期>=270时，允许输出的载波零点必为高，本模块明确保留这一沿规则。
- -32768先转16位无符号补码幅值32768，再饱和到255。

结构分为幅值/宽度组合计算、载波、消隐/符号/脉宽、方向脚、PWM五部分；四个短always块，无大状态机。宽度算术保留32位结果；合法最大商4722，后端综合器可优化高常量位。仅lint不能证明资源和时序结果。

## 验证

[测试台](../tb/tb_motro.v)与[运行脚本](run_motor_tests.py)执行：

1. 65536种signed16命令的幅值及脉宽，对比独立整数数学公式和旧normalized_width。
2. 实际5000拍周期，稳定幅值的高电平计数与方向检查。
3. 正反向、零、disable、超范围、-32768、周期中途幅值变化、消隐重换向与异步复位。
4. 对新旧三个输出每拍比较，并以独立周期模型检查新实现。
5. Verilog2005/2012分别编译仿真，运行前后核对相关文件哈希。

最终Verilog2005/2012各自通过684245个运行周期、687526次检查，全部65536种signed16值及10个PWM周期计数通过；覆盖282次消隐期间重换向、载波0/4999边界及2次异步复位。运行期间源码哈希稳定。

Verilator 5.050严格--lint-only --Wall通过，零警告、无豁免。源码109行，最长91列，无Tab。

编译镜像写入临时目录，日志及结果存本目录。详细证据见[motor_test_results.json](motor_test_results.json)。没有修改旧驱动，没有执行引脚约束、综合、布局布线或硬件加载；目前没有控制顶层连接两个V3模块。
