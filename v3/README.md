## 当前模块

[adc_pend.v](src/adc_pend.v)集中实现：

```text
外部10位ADC → 每9375拍锁存 → 每8点分组平均 → 原有一阶IIR → 四倍标度输出
                                  ↓
                            摆角映射 → 角差测速 → 速度低通 → 观测有效性发布
```

固定参数来自重建时的v2.2活动代码：50MHz系统时钟、25MHz ADC接口时钟、9375拍采样间隔、8点平均、C04=128（权重128/256=1/2）。使用命名localparam保存当前参数，没有cfg总线或运行时滤波系数输入。未来模块按用户确认的现有参数逐个建立，不预先搬入整套旧控制逻辑。

## 算法与时序

八点分组平均为floor(sum/8)，不是滑动平均。IIR内部保留Q8小数：

```text
首样本：y = average * 256
后续：  y = y + trunc_zero((average*256-y)*128/256)
输出：  angle_x4 = floor(y/64)
```

负增量向零截断，保留原算法。不能先将y截为整数后再乘4，否则会损失四分之一码。四倍标度不等于ADC硬件精度提高两位，也不是将0..1023重新映射到0..4095。

每9375个系统沿锁存引脚，下一沿累计。第8点累计沿发布平均值，再下一沿滤波接收：首样本立即建初值并发布，后续在接收后第1沿乘法、第2沿发布。没有大状态机，四个短时序块分别负责接口时钟、采样、平均、滤波流水。

filter_clear优先于新平均事件和在途滤波，清零结果与ready；与接收同沿的平均事件被丢弃，下一有效平均值重新建初值。清除不改变ADC输出时钟和1.5ms平均发布节奏。
